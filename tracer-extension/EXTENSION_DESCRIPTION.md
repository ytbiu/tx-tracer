# Chrome Web Store Product Description

## Product Name
**Transaction Tracer Helper**

## Short Description (Summary)
Instantly trace transactions on Etherscan, BscScan, BaseScan, and Solana explorers with a single click.

## Detailed Description

**Transaction Tracer Helper** is the ultimate tool for blockchain developers and security researchers. It seamlessly integrates a "Trace" button directly into popular blockchain explorers, allowing you to instantly visualize and debug transaction execution flows without manually copying and pasting transaction hashes.

When you view a transaction on a supported explorer, this extension injects a convenient **"Trace with Tx-Tracer"** button. Clicking it opens the powerful Tx-Tracer visualization tool, giving you deep insights into internal calls, state changes, and execution paths.

### 🚀 Key Features
*   **One-Click Tracing**: No more copy-pasting. Jump straight from the explorer to the trace view.
*   **Multi-Chain Support**: Works out-of-the-box with major EVM and Solana explorers.
*   **Seamless Integration**: The button blends naturally into the explorer's UI, looking like a native feature.
*   **Privacy Focused**: Runs locally in your browser. No user data is collected or transmitted.

### 🌐 Supported Explorers
*   **Ethereum**: Etherscan (etherscan.io)
*   **Binance Smart Chain**: BscScan (bscscan.com)
*   **Base**: BaseScan (basescan.org)
*   **Solana**: Solana Explorer (explorer.solana.com) & Solscan (solscan.io)

### 🛠 Who is this for?
*   **Smart Contract Developers**: Debug failed transactions and understand complex interactions.
*   **Security Analysts**: Analyze exploit flows and fund movements.
*   **DeFi Users**: Verify what a transaction actually did under the hood.

## Privacy Policy & Permissions
This extension requires access to `*.etherscan.io`, `*.bscscan.com`, `*.basescan.org`, `*.solscan.io`, and `explorer.solana.com` solely to insert the "Trace" button into the page.
*   **No Personal Data Collection**: We do not track your browsing history or collect any personal information.
*   **No Remote Code**: All logic is contained within the extension.
